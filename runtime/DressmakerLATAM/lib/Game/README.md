# Game references

Copy these DLLs here from the Dressmaker game managed folder, usually `Dressmaker_Data/Managed/`:

- `UnityEngine.CoreModule.dll`
- `Unity.Localization.dll`
- `Unity.Addressables.dll`
- `Unity.ResourceManager.dll`

Use the DLLs from the same installed game version that will be used for runtime testing.
